## 本次测试额外发现并修复

1. PostgreSQL 聚合 bigint 返回 Decimal，费用指标被 Prometheus 序列化过滤；现统一转为整数。
2. 被动副本缓存任务状态不刷新，跨进程任务结束后仍显示运行中；现从数据库刷新，并结束 SSE。
3. Cookie 登录没有读取受信任身份表中的角色，导致数据库 operator 无法访问运维接口；现按企业、身份源、主体和本地用户精确关联，每次请求读取，撤权立即生效。
4. GC 可能跟随存储目录 symlink；现跳过 symlink，校验已登记结果 ID，不越界删除。
5. 测试库保护检查整个 DSN 是否含 test，密码含 test 也可能误判；现只检查实际数据库名称。
6. 会话摘要原本发生在运行预算钩子绑定之前；现移到同一受控执行与清理路径，租户与运行预算均可覆盖。

7. 脱敏发布包在全新目录运行时暴露了原有测试对本机部署开关和模型凭据的隐式依赖；改为显式测试配置，并将解压发布包、校验 SHA256SUMS、全套测试加入 CI。
