这套机制怎么工作

验证方式
中台把账号密码转给平台自己的登录接口校验，不保存也不校验密码。 校验通过后按平台返回的用户标识绑定身份、发中台会话。
身份源
同一个身份源下的多个入口，登录后落到同一个中台账号。想让两个平台 共用账号，把「身份源」填成一样。
租户
从这个平台首次登录的人，默认落在这个租户里。已有绑定的人不受影响。
票据 / OIDC
这两种接入方式还不在这里管：它们要公钥或客户端密钥，目前仍走 AUTH_CONNECTIONS / OIDC_* 配置。
